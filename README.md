# PsyHelp — платформа для психологов

Онлайн-платформа для психологических консультаций с универсальным планировщиком, видеочатом и мессенджером.

## 🎯 Цель проекта

Создать защищённое пространство, где:
- Клиенты находят психологов, записываются на сессии, оплачивают, общаются.
- Психологи управляют расписанием, клиентами, публикуют статьи.
- Планировщик работает как универсальный календарь для жизни.
