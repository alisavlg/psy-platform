# PsyHelp — Документация

## Требования и план (что должно быть)
- `requirements.md` — общие требования к системе
- `roles.md` — роли, права, делегирование
- `api.md` — будущий API (для backend)
- `database.md` — будущая схема БД (для backend)

## Текущее состояние (что есть сейчас)
- `architecture.md` — карта проекта: файлы, ключи, сценарии
- `state.md` — что сделано / что в работе / что дальше
- `changelog.md` — история изменений по датам

## Правила разработки
- `theme-guide.md` — правила оформления: переменные, стили, структура CSS

## Что читать когда

- **Начинаю новый чат с ИИ** → присылаю `state.md` + `architecture.md` + `theme-guide.md`
- **Хочу вспомнить, как устроен сценарий** → `architecture.md`, раздел 6
- **Хочу поменять цвет кнопок** → `theme-guide.md`, раздел 3.1
- **Планирую переезд на backend** → `api.md` + `database.md`
- **Не уверена, что уже сделано** → `state.md`
