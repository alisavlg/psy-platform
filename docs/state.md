## Философия проекта

**Eupsy** — от греческого *εὐψυχία* (eupsychia) — «благая душа».

Абрахам Маслоу использовал это слово для «Хорошего Общества» — социума, в котором человек может быть здоров и реализовать себя.

Ключевая идея:
> Общество не может быть здоровым, если его души больны.
> Благое общество состоит из благих душ.

Eupsy — это среда, где:
- Психолог и клиент встречаются без лишних контактов.
- Каждая сессия — шаг к целостности.
- Одна душа за раз — так строится благое общество.

**PsyHelp** — рабочее название проекта. **Eupsy** — продукт на домене `eupsy.ru`.

## Что работает в облаке

### Аутентификация
- Регистрация, вход, выход — Supabase Auth
- Сессия и роли — `auth-guard.js`
- Защищено: `client.html`, `dashboard.html`, `admin.html`, `application-history.html`
- `admin.html` — только для owner / admin / moderator

### Таблицы Supabase

| Таблица | Что |
|---------|-----|
| `profiles` | Пользователи (роли, ФИО, транслируемое имя, код, статус, аватар, часовой пояс) |
| `psychologist_profiles` | Психологи (специализация, стаж, цена, рейтинг, аватар) |
| `events` | Календарь (free / session / personal / work / health / study) |
| `sessions` | Бронирования |
| `reviews` | Отзывы |
| `notifications` | Уведомления |
| `chats` + `messages` | Мессенджер |
| `applications` | Заявки на психолога |
| `application_events` | История заявки |
| `client_notes` | Заметки психолога о клиенте |

### Storage
- `avatars` (public) — фото профиля
- `documents` (public) — дипломы, сертификаты, практика, другое

### Триггеры
- `trg_reviews_update_rating`
- `trg_application_events`
- `trg_sync_client_avatar`
- `trg_sync_psychologist_avatar`

### RPC-функции
- `approve_application`, `reject_application`, `request_attention`
- `resubmit_application`

## Что работает по-настоящему

1. Регистрация / вход / выход
2. Каталог психологов (с фото)
3. Профиль психолога + бронирование
4. Календарь (слоты) + «Заполнить будни / выходные»
5. Мои сессии клиента — с фото психолога
6. Сессии психолога — с фото клиента + «Написать в чат»
7. Отмена с возвратом слота
8. Отзывы + автоматический пересчёт рейтинга
9. Заявка на психолога: фото + документы + модерация + история
10. Уведомления + напоминания 24ч / 1ч
11. Мессенджер с фото собеседников
12. Видеокомната (Jitsi)
13. Аватары везде
14. Часовой пояс психолога — сохраняется в `profiles.timezone`

## Формы и лимиты

**Заявка на психолога:**
- Фото — обязательно. JPG / PNG / WebP, до 3 МБ. Сжимается до 1600px
- Дипломы — обязательно. До 5 файлов, общий ≤ 5 МБ
- Сертификаты — до 10 файлов, общий ≤ 10 МБ
- Практика — до 5 файлов, общий ≤ 10 МБ
- Другое — до 10 файлов, общий ≤ 10 МБ
