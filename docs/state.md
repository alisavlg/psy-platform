## Что работает по-настоящему

### Аутентификация
- Регистрация, вход, выход — Supabase Auth
- Проверка сессии и роли — `auth-guard.js`
- Защищённые страницы: `client.html`, `dashboard.html`, `admin.html`, `application-history.html`
- `admin.html` — только для owner / admin / moderator

### Таблицы Supabase

| Таблица | Что хранит |
|---------|-----------|
| `profiles` | Пользователи (роли, ФИО, транслируемое имя, код, статус, аватар) |
| `psychologist_profiles` | Психологи (специализация, стаж, цена, рейтинг, аватар) |
| `events` | Календарь (free / session / personal / work / health / study) |
| `sessions` | Бронирования (status, refund, reminders) |
| `reviews` | Отзывы. Триггер `update_psychologist_rating` пересчитывает рейтинг |
| `notifications` | Уведомления |
| `chats` + `messages` | Мессенджер |
| `applications` | Заявки на психолога (+ `documents jsonb`, `qualifications`) |
| `application_events` | История заявки (+ `author_role`, `snapshot jsonb`) |

### Storage
- `avatars` (public) — фото профиля клиента и психолога
- `documents` (public) — дипломы, сертификаты, практика, другое

### Триггеры
- `trg_reviews_update_rating` — пересчёт рейтинга психолога
- `trg_application_events` — запись события в `application_events` при любом изменении `applications` (включая снимок)

### RPC-функции
- `approve_application(app_id, comment)` — одобрить + создать `psychologist_profiles` + роль psychologist
- `reject_application(app_id, comment)` — отклонить + снять роль psychologist
- `request_attention(app_id, comment)` — на доработку + снять роль psychologist
- `resubmit_application(...)` — повторная подача с фото и документами

## Что работает по-настоящему

1. Регистрация / вход / выход
2. Каталог психологов (с фото)
3. Профиль психолога (с фото) + бронирование
4. Календарь (слоты) + «Заполнить будни / выходные»
5. Мои сессии (клиент) — с фото психолога
6. Сессии психолога — **без фото клиента** (в работе)
7. Отмена с возвратом слота
8. Отзывы + автоматический пересчёт рейтинга
9. Заявка на психолога:
   - Фото + 4 категории документов + квалификация
   - Модерация + повторная подача
   - История со снимками каждого этапа
10. Уведомления + напоминания 24ч / 1ч
11. Мессенджер (с фото собеседников)
12. Видеокомната (Jitsi)
13. Аватары в: каталоге, профиле, меню, чате, сессиях клиента

- Сертификаты — до 10 файлов, общий ≤ 10 МБ, каждый ≤ 3 МБ
- Практика — до 5 файлов, общий ≤ 10 МБ, каждый ≤ 3 МБ
