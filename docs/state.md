## Что работает в облаке

### Аутентификация
- Регистрация, вход, выход — Supabase Auth
- Сессия и роли — `auth-guard.js`
- Защищено: `client.html`, `dashboard.html`, `admin.html`, `application-history.html`
- `admin.html` — только для owner / admin / moderator

### Таблицы Supabase

| Таблица | Что |
|---------|-----|
| `profiles` | Пользователи (роли, ФИО, транслируемое имя, код, статус, аватар) |
| `psychologist_profiles` | Психологи (специализация, стаж, цена, рейтинг, аватар) |
| `events` | Календарь (free / session / personal / work / health / study) |
| `sessions` | Бронирования |
| `reviews` | Отзывы |
| `notifications` | Уведомления |
| `chats` + `messages` | Мессенджер |
| `applications` | Заявки на психолога |
| `application_events` | История заявки |

### Storage
- `avatars` (public) — фото профиля
- `documents` (public) — дипломы, сертификаты, практика, другое

### Триггеры
- `trg_reviews_update_rating` — пересчёт рейтинга при изменении `reviews`
- `trg_application_events` — событие в `application_events` при изменении `applications` (+ снимок)
- `trg_sync_client_avatar` — синхронизация `avatar_url` клиента в `chats.client_avatar`
- `trg_sync_psychologist_avatar` — синхронизация `avatar_url` психолога в `chats.psychologist_avatar`

### RPC-функции
- `approve_application` — одобрить заявку
- `reject_application` — отклонить
- `request_attention` — на доработку
- `resubmit_application` — повторная подача

## Что работает по-настоящему

1. Регистрация / вход / выход
2. Каталог психологов (с фото)
3. Профиль психолога (с фото) + бронирование
4. Календарь (слоты) + «Заполнить будни / выходные»
5. Мои сессии клиента — с фото психолога
6. Сессии психолога — с фото клиента + «Написать в чат»
7. Отмена с возвратом слота
8. Отзывы + автоматический пересчёт рейтинга
9. Заявка на психолога:
   - Фото + 4 категории документов + квалификация
   - Модерация + повторная подача
   - История со снимками каждого этапа
10. Уведомления + напоминания 24ч / 1ч
11. Мессенджер с фото собеседников
12. Видеокомната (Jitsi)
13. Аватары везде: каталог, профиль, меню, чат, сессии клиента, сессии психолога

## Формы и лимиты

**Заявка на психолога:**
- Фото — обязательно. JPG / PNG / WebP, до 3 МБ. Картинки сжимаются до 1600px
- Дипломы — обязательны. До 5 файлов, общий ≤ 5 МБ, каждый ≤ 3 МБ
- Сертификаты — до 10 файлов, общий ≤ 10 МБ, каждый ≤ 3 МБ
- Практика (супервизии, личная терапия) — до 5 файлов, общий ≤ 10 МБ, каждый ≤ 3 МБ
- Другое (награды, публикации) — до 10 файлов, общий ≤ 10 МБ, каждый ≤ 3 МБ
