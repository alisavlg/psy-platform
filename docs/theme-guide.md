# PsyHelp — Правила оформления (тема и CSS)

**Версия:** 1.0
**Последнее обновление:** 24 сентября 2026

---

## 1. Главный принцип

**Все настройки оформления живут в одном файле — `assets/css/theme.css`.**

Остальные CSS-файлы **только ссылаются** на переменные из темы. Не задают цвета, шрифты и размеры напрямую.

**Зачем это нужно:**
- Поменять цвет кнопок во всём сайте — одна строка.
- Единый стиль без расхождений.
- Меньше кода, легче поддерживать.

---

## 2. Где живут переменные

Все переменные объявлены в `:root` внутри `assets/css/theme.css`.

```css
:root {
    --color-primary: #4a90e2;
    --radius-button: 50px;
    /* ... */
}
