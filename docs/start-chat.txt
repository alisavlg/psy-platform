Привет. Я делаю Eupsy — платформу для психологов.

Философия: Eupsy — от греческого εὐψυχία («благая душа»). 
Общество не может быть здоровым, если его души больны. 
Благое общество состоит из благих душ. Eupsy — среда, где 
психолог и клиент встречаются без лишних контактов.

Стек:
- Фронтенд: HTML + CSS + JS, локально через Live Server
- Backend: Supabase (Auth, PostgreSQL, RLS, Storage)
- Видео: Jitsi Meet (публичный, лимит 5 мин). В планах — JaaS от 8x8
- Хостинг: Vercel + домен eupsy.ru (в процессе)
- Репозиторий: github.com/alisavlg/psy-platform

Текущий этап: почти завершили переезд на Supabase. 
Готовимся к хостингу на Vercel + домен eupsy.ru.

Что уже в облаке:
- Регистрация, вход, сессии, роли
- Профили, каталог психологов, слоты, бронирование
- Сессии клиента и психолога
- Отзывы с рейтингом
- Заявки на психолога: фото + документы + модерация + история
- Уведомления + напоминания 24ч/1ч
- Мессенджер (chats + messages)
- Аватары в Storage
- Видеокомната (Jitsi)
- Часовой пояс психолога

Что осталось:
- Отчёты психолога (сейчас заглушка)
- Хостинг Vercel + домен eupsy.ru
- JaaS от 8x8 (замена публичного Jitsi)
- Оплата (ЮKassa)
