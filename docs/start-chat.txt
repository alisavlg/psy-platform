Привет. Я делаю PsyHelp — платформу для психологов.

Стек:
- Фронтенд: HTML + CSS + JS, локально через Live Server
- Backend: Supabase (Auth, PostgreSQL, RLS, Storage)
- Видео: Jitsi Meet (пока публичный, есть лимит 5 мин)
- Репозиторий: github.com/alisavlg/psy-platform

Текущий этап: почти завершили переезд на Supabase.

Что уже в облаке:
- Регистрация, вход, сессии
- Профили, роли
- Каталог психологов
- Слоты и календарь
- Сессии и бронирование
- Отзывы + автоматический пересчёт рейтинга
- Уведомления + напоминания за 24ч и 1ч
- Мессенджер (chats + messages)
- Заявки на психолога + модерация + история заявки (application_events + триггер)
- Аватары в Storage
- Видеокомната (Jitsi)

Что осталось:
- Отображение аватаров во всех местах (каталог, чат, меню, сессии)
- Файлы дипломов в Storage
- Раздел «Клиенты» психолога — старая модель на localStorage
- Хостинг + домен
- ЮKassa — оплата

Правила работы:
1. Сначала согласуй логику — потом код.
2. Запрашивай файлы перед правками. Не переписывай целиком.
3. Точечные правки — экономия чата.
4. Если файл уже ломался — предложи замену целиком.
